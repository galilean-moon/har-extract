# har-extract
har-extract is a simple PS/shell script that accepts a .HAR (HTTP Archive File) as input. The shell script utilizes jq to display URL redirects and IPs from a browser interaction with a website. It also displays NS records for the website's apex domain.

***

### Shell script (Debian/Ubuntu):
**This program requires jq and dig to run.**

You can install jq by running the command "apt-get install jq" and dig by running the command "apt-get install dnsutils" (Debian/Ubuntu).

### PowerShell script:

No requirements.
